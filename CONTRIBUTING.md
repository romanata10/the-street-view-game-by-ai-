# Участие в разработке ГЕОСВОИ

Спасибо за интерес к проекту! Можно улучшать игру, интерфейс, документацию и библиотеку локаций.

## Настройка окружения

```bash
npm ci
npm run dev
```

Требуется Node.js 20.19+. Перед Pull Request выполните:

```bash
npm run test:content
npm run build
```

CI дополнительно запускает production healthcheck.

## Как добавить город

1. Добавьте две equirectangular-панорамы **2:1** в `public/panoramas`.
2. Добавьте город в `CITIES` в `shared/data.ts`:
   - уникальный `id`;
   - название, страна и флаг;
   - центральные координаты и zoom карты;
   - обложка, цвет и описание.
3. Добавьте минимум две записи в `LOCATIONS`:
   - уникальный `id`;
   - `cityId` нового города;
   - понятное название места;
   - координаты реальной цели;
   - путь к изображению;
   - отдельная подсказка и стартовый heading.
4. Проверьте покрытие Google Street View рядом с каждой координатой.
5. Запустите `npm run test:content`.

Не используйте изображения без права на публикацию. Встроенные AI-сцены должны оставаться помеченными как иллюстративные, а не как фотографии реальных координат.

## Как изменить правила матча

Сервер в `server/index.ts` является источником истины для:

- выбора локации;
- таймера;
- принятия ответа;
- расстояния и очков;
- монет и предметов;
- атак и защиты.

Не переносите критичные вычисления только на клиент: это упростит изменение состояния в многопользовательском матче. Общие типы сообщений находятся в `shared/types.ts`.

## Стиль изменений

- TypeScript strict mode, без отключения проверок ради сборки.
- React-компоненты не должны напрямую удалять DOM-узлы, которыми управляет React. Для Three.js/Google используйте отдельные пустые контейнеры.
- Новые внешние сервисы должны иметь понятный fallback.
- Не раскрывайте правильную точку на мини-карте до результата раунда.
- Сохраняйте русскую локализацию и мобильную адаптацию.
- Не коммитьте `.env`, ключи, `node_modules`, `dist` и временные screenshots.

## Pull Request

1. Создайте отдельную ветку.
2. Опишите изменение и способ проверки.
3. Приложите screenshot для заметных UI-изменений.
4. Дождитесь зелёного CI.
5. Укажите документацию, которую обновили, если менялись запуск или правила игры.
