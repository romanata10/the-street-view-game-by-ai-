# Настройка Google Maps и Street View

ГЕОСВОИ использует **Maps JavaScript API**, `StreetViewService` и `StreetViewPanorama` для реальных уличных сцен и фиксированных точек. Ключ не хранится в репозитории.

## 1. Подготовьте проект Google Cloud

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект или выберите существующий.
3. Подключите billing, если этого требует ваш аккаунт.
4. В **APIs & Services → Library** включите **Maps JavaScript API**.
5. Проверьте условия использования, квоты и актуальные цены Google перед публичным запуском.

Отдельный Street View Static API для текущей интеграции не требуется: приложение использует интерактивный Street View из Maps JavaScript API.

## 2. Создайте браузерный ключ

1. Перейдите в **APIs & Services → Credentials**.
2. Нажмите **Create credentials → API key**.
3. Откройте настройки ключа.
4. В **Application restrictions** выберите **Websites / HTTP referrers**.
5. Добавьте только свои адреса, например:

```text
http://localhost:3000/*
http://127.0.0.1:3000/*
https://maps.example.com/*
```

Для preview- или production-домена добавьте его отдельно. Не оставляйте production-ключ без ограничений.

6. В **API restrictions** разрешите только **Maps JavaScript API**, если ключ больше нигде не используется.

> Браузерный ключ неизбежно попадает в client bundle. Это нормально для Maps JavaScript API, но доменные ограничения и квоты обязательны. Не публикуйте секреты сервисных аккаунтов и не отправляйте ключи в чат.

## 3. Добавьте ключ в приложение

Создайте `.env` в корне проекта:

```env
VITE_GOOGLE_MAPS_API_KEY=ваш_ключ
PORT=3000
```

Файл `.env` уже исключён из Git. Затем:

```bash
npm run dev
```

Если dev-сервер уже работал, остановите и запустите его заново. Для production:

```bash
npm run build
npm start
```

Vite подставляет `VITE_*` переменные во время сборки, поэтому изменение ключа требует новой сборки.

## 4. Проверьте подключение

1. Откройте главную страницу.
2. В блоке «Что видно на экране» должно появиться **«Google Maps API подключён: улицы и точки»**.
3. Запустите матч «С ботом».
4. Во время загрузки появится «Загружаем Google Street View…».
5. Проверьте оба режима:
   - **Street View:** стрелки и переходы по улицам включены;
   - **Панорамы:** вращение и zoom работают, переходы отключены.

## Как выбирается панорама

Для каждой локации приложение вызывает:

- координаты из `LOCATIONS` в `shared/data.ts`;
- `StreetViewService.getPanorama`;
- радиус поиска **250 м**;
- `StreetViewPreference.NEAREST`;
- `StreetViewSource.OUTDOOR`.

После успешного поиска сцена открывается по её `panoId`. Этот ID также передаётся другим участникам для корректного отображения аватаров в одной сцене.

Если ответа нет 12 секунд, API не загрузился 15 секунд или панорама не найдена, включается резервная Three.js-сцена с уведомлением.

## Частые ошибки

### `ApiNotActivatedMapError`

Maps JavaScript API не включён в выбранном проекте. Включите API, подождите несколько минут и обновите страницу.

### `RefererNotAllowedMapError`

Текущий домен отсутствует в HTTP referrer restrictions. Добавьте точный домен и порт, включая preview-домен, затем обновите страницу. Проверьте `http` против `https`.

### `REQUEST_DENIED`

Проверьте:

- включён ли Maps JavaScript API именно в проекте ключа;
- не запрещает ли API restrictions нужный API;
- активен ли billing;
- не исчерпаны ли квоты;
- не был ли ключ удалён или заменён.

### `InvalidKeyMapError`

Проверьте значение `VITE_GOOGLE_MAPS_API_KEY`, отсутствие пробелов/кавычек и перезапуск после изменения `.env`.

### Панорама не найдена

Не каждая координата имеет outdoor-покрытие в радиусе 250 м. Можно увеличить радиус в `PanoramaViewer.tsx` или уточнить координаты локации. После изменения проверьте начисление очков: цель должна оставаться рядом с фактической сценой.

### Работает локально, но не на сервере

Production использует ключ, встроенный во время `npm run build`. Добавьте production-домен в ограничения и пересоберите приложение с нужной переменной. В Docker ключ передаётся как build argument:

```bash
docker build \
  --build-arg VITE_GOOGLE_MAPS_API_KEY=ваш_ключ \
  -t geosvoi .
```

## Квоты и стоимость

Настройте в Google Cloud:

- бюджет и уведомления о расходах;
- суточные/пользовательские квоты;
- мониторинг запросов Maps JavaScript API;
- ограничение ключей по доменам и API.

Не отключайте резервные сцены: они позволяют продолжить дружеский матч при временной ошибке API или исчерпании доступа.
