# ГЕОСВОИ 1.0.0 — первый публичный релиз

Мультиплеерная браузерная игра для дружеских географических соревнований: Google Street View, комнаты по приглашению, восемь городов, гаджеты и финальный подиум.

## Быстрый старт

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000` и нажмите **«С ботом»** для теста или **«Создать комнату»**, чтобы позвать друзей.

Docker:

```bash
docker compose up --build
```

## Главные возможности

- Комнаты до 8 игроков с кодом, ссылкой, чатом и готовностью.
- 8 городов и 16 локаций без повторов до исчерпания набора.
- Google Street View: движение по улицам и фиксированные точки.
- Классика, «Кто ближе» и блиц на 45 секунд.
- Подсказка, чёрный экран, ускорение, щит, удвоение и постоянная оптика.
- Присутствие друзей в панораме и на карте.
- Результаты раундов, монеты, магазин и реванш.
- Резервные панорамы и автономная карта при недоступных внешних сервисах.

## Production bundle

К архиву `geosvoi-1.0.0-production.tar.gz` приложены собранный клиент, сервер и общие игровые данные. Для запуска:

```bash
tar -xzf geosvoi-1.0.0-production.tar.gz
cd geosvoi-1.0.0
npm ci --omit=dev
npm start
```

Нужен Node.js 20.19+. Google API key в архив не включён; резервный режим работает без него. Для включения Google пересоберите клиент из исходников по инструкции.

## Проверки

- `npm run test:content` — 8 городов, 16 панорам и уникальные подсказки.
- `npm run build` — TypeScript и Vite production build.
- Браузерный сценарий: меню → обучение → лобби → бот → матч; отдельно проверены подсказка, магазин, ответ и результат.
- Multiplayer: создание, вход, чат, готовность, ответы, очки и гаджеты.
- Google integration: навигация Street View включена, фиксированные точки блокируют переходы, `panoId` передаётся по WebSocket.
