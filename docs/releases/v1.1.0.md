# ГЕОСВОИ 1.1.0 — свободная прогулка с другом

В этом релизе появился отдельный совместный режим без таймера и соревнования, избранные панорамы и встроенный центр загрузок. Присутствие друга теперь явно показывается во всех режимах.

## Что нового

- **«Погуляй с другом»** — свободная прогулка по 16 встроенным местам и Google Street View без таймера, ответов, очков и раундов.
- **Независимые места** — каждый участник меняет свою сцену, не перемещая остальных.
- **Переход к другу** — кнопка «К другу» открывает текущую локацию друга, а в Google — точный `panoId` и направление взгляда.
- **Подключение после старта** — гость входит по ссылке в уже идущую прогулку и появляется в сцене хоста.
- **Избранные места** — сохраняются в браузере вместе с Google `panoId` и направлением взгляда; вкладка «Избранное» открывает их одним нажатием.
- **«В том же месте» во всех режимах** — постоянный баннер, статус в списке игроков и уведомление о встрече работают и в прогулке, и в соревновательном матче.
- **Центр загрузок** — кнопка «Скачать» с готовыми production ZIP/TAR.GZ, исходниками, пошаговой установкой и проверкой SHA-256.

## Быстрый старт из production-архива

```bash
unzip geosvoi-1.1.0-production.zip
cd geosvoi-1.1.0
npm ci --omit=dev
npm start
```

Либо TAR.GZ:

```bash
tar -xzf geosvoi-1.1.0-production.tar.gz
cd geosvoi-1.1.0
npm ci --omit=dev
npm start
```

Откройте `http://localhost:3000`. Нужен Node.js 20.19+, рекомендуется Node.js 22 LTS.

Из исходников:

```bash
npm ci
npm run dev
```

## Как позвать друга в прогулку

1. На главной странице нажмите **«Погулять с другом»**.
2. Скопируйте ссылку-приглашение или продиктуйте код комнаты.
3. Друг открывает ссылку и нажимает **«Я готов играть»**.
4. Хост нажимает **«Начать прогулку»**.
5. Меняйте места кнопкой **«Сменить место»**, сохраняйте любимые панорамы и переходите к другу кнопкой **«К другу»**.

Друг может подключиться и после старта — он окажется в текущей сцене хоста.

## Проверки

- `npm run test:content` — 8 городов, 16 панорам и уникальные подсказки.
- `npm run build` — TypeScript и Vite production build.
- Два изолированных браузерных профиля: старт прогулки, 16 мест, независимые сцены, переход к другу, избранное, чат и позднее подключение.
- Обычный матч с двумя реальными игроками: баннер и статус «В том же месте».
- Сборка архивов: `unzip -t`, `npm ci --omit=dev`, ответы `/`, `/api/health` и `/ws` из распакованного production ZIP.
- Мобильная вёрстка 390×844 без горизонтального скролла и пересечений панелей.
