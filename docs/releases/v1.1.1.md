# ГЕОСВОИ 1.1.1 — обучение установке внутри игры

Небольшое обновление обучения: теперь пошаговая установка доступна не только в центре загрузок, но и во встроенном «Как играть».

## Что нового

- **Вкладка «Скачать» в центре обучения** — четыре шага: production ZIP, Node.js 20.19+, `npm ci --omit=dev` и `npm start`, запуск на `http://localhost:3000`.
- **Переход в центр загрузок** прямо из обучения: кнопка открывает production ZIP, TAR.GZ, исходники и страницу релизов.
- **Обучение доступно на телефоне:** на главной появилась ссылка «Как играть и установить», потому что верхнее меню на узких экранах скрыто.
- **Пояснение про форматы** — RAR не нужен; ZIP исходников нужен только для разработки с `npm run dev`.
- Обновлены скриншоты обучения и инструкция [DOWNLOAD.ru.md](https://github.com/romanata10/the-street-view-game-by-ai-/blob/main/docs/DOWNLOAD.ru.md).

## Быстрый старт

```bash
unzip geosvoi-1.1.1-production.zip
cd geosvoi-1.1.1
npm ci --omit=dev
npm start
```

Либо TAR.GZ:

```bash
tar -xzf geosvoi-1.1.1-production.tar.gz
cd geosvoi-1.1.1
npm ci --omit=dev
npm start
```

Откройте `http://localhost:3000`. Нужен Node.js 20.19+, рекомендуется Node.js 22 LTS.
